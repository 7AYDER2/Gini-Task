# 🚀 Mini App UI Task — Gini

This task involves building a **Mini App UI** using the following tech stack:

- ⚛️ React
- 🧠 TypeScript
- ⚡ Vite
- 📱 PWA (Progressive Web App) support

---

## 📋 Objective

Create a lightweight, responsive UI for a **Mini App** that:

- Follows a clean and modern design.
- Works seamlessly across mobile and desktop.
- Is installable as a PWA.
- Is built with scalability and modularity in mind.

---

## 🧰 Tech Stack

| Tech       | Purpose                      |
|------------|------------------------------|
| **React**  | UI library                   |
| **TypeScript** | Static typing for safer code |
| **Vite**   | Fast dev server & build tool |
| **PWA**    | Offline support & installable |
